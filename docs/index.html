Gezer & Finder, honestly.

macOS doesn't let any app replace Finder — it always runs, and parts of the system only talk to it. But Gezer can take over every folder that opens through Launch Services.

✓Opens in Gezer

    –Stays with Finder

      Make Gezer the folder handler
      $ brew install duti
$ duti -s com.gezer.app public.folder viewer   # folders open in Gezer
$ duti -s com.apple.finder public.folder viewer  # undo: give them back to Finder

      Or skip all that: keep Gezer in the Dock and drop folders on it, use Finder's Open With › Gezer, or run open -a Gezer ~/Downloads.
