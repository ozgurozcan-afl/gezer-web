# Gezer

Website and downloads for Gezer, a Windows Explorer–style file manager for macOS.

Website: https://ozgurozcan-afl.github.io/gezer-web/

Download: https://github.com/ozgurozcan-afl/gezer-web/releases/latest/download/Gezer.dmg

The site is a single static page in `docs/` (served by GitHub Pages from the `main` branch, `/docs` folder).
